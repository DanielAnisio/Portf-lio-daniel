# Portfólio — Daniel Oliveira

Portfólio profissional responsivo, desenvolvido em HTML, CSS e JavaScript puro.

## Executar localmente
Abra `index.html` no navegador. Não é necessário instalar dependências.

## Personalizar
- Edite o conteúdo em `index.html`.
- Edite cores, layout e fontes em `style.css`.
- Adicione e-mail, GitHub e LinkedIn no objeto `contato` no início de `script.js`.
- Não publique informações confidenciais ou internas do ambiente de trabalho.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub (por exemplo, `portfolio-daniel`).
2. No GitHub Desktop, use **File > Add local repository**. Se necessário, inicialize um repositório Git nesta pasta primeiro (Git Bash: `git init`, `git add .`, `git commit -m "Portfolio inicial"`).
3. Publique o repositório no GitHub.
4. No GitHub, abra **Settings > Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
6. Aguarde a publicação. O endereço costuma seguir `https://SEU-USUARIO.github.io/portfolio-daniel/`.

## Estrutura
- `index.html` — conteúdo e marcação.
- `style.css` — visual e responsividade.
- `script.js` — filtros, menu e configurações de contato.

O design foi criado como versão própria. Para reproduzir fielmente um projeto do Google Stitch, envie imagens ou o código exportado do Stitch.
